# Teach-Me

Prototype d'application e-learning pour un cabinet de formation professionnelle.

Ce dépôt contient un exemple minimal de pages web, un squelette d'application React Native et quelques fichiers Laravel pour le backend.

## Contenu
- **index.html** : page d'accueil HTML/CSS.
- **mobile/** : prototype React Native.
- **backend/** : squelette Laravel avec route de paiement.

## Fonctionnalités envisagées
- Inscription des utilisateurs et authentification
- Catalogue de formations en direct ou en différé
- Paiement sécurisé via Stripe
- Tableau de bord avec suivi de progression et certificats
- Messagerie interne et espace formateur
- Intégration Zoom pour les visioconférences
